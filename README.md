研究主題：如何透過開源軟體與串流網站實現同步撥放媒體內容

- guest.json：測試用點播單接口

- recha-link.json：為測試用多合一接口

- recha-sex.json：蒐集github各設計者所列性感接口

- recha-movie.json：蒐集github各設計者所列點撥接口

- recha-live.json：蒐集github各設計者所列直播接口

3. 接口所用的jar太過繁多，應該盡可能刪減，盡量單一化，以減少緩存
